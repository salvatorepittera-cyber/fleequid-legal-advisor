# Note RO (rumeno) — decisioni vincolanti dal blocco k01 revisionato
- Registro: condiții generale B2B di un giurista rumeno. Percentuali "30 %". "Marketplace" invariabile (mai "Marketplace-ul").
- risoluzione della compravendita per inadempimento = "rezoluțiune" (verbo "a declara rezoluțiunea Contractului", participio "rezolvit"), mai "reziliere/a rezilia" (resta solo per i rapporti di durata); clausola risolutiva espressa = "clauză rezolutorie expresă"; risoluzione ex art. 1456 = "rezoluțiune în temeiul art. 1456 din Codul civil italian".
- commissionario/committente = comisionar / comitent (mai "mandant", "agent de vânzare", "părți reprezentate"); incarico = "însărcinare" (mai "sarcină", che è Gravame = Sarcină); Intermediar pur (mai "simplu intermediar").
- Pagamento anticipato (termine definito, art. 13) = "Avans"; "pagamento anticipato" minuscolo dell'art. 22.9 = "plată anticipată"; caparra confirmatoria/penitenziale = arvună confirmatorie / penalizatoare.
- 1 Euro Auction(s) in inglese; Bază de licitație; Ofertă maximă; Cumpără pe loc; Statut Opționat; Acord obligatoriu; Vânzare în comision; Anunț (Fișă de Licitație); Listă de tarife Fleequid; PMAV; VSU.
- fonti contrattuali = "surse contractuale"; controproposta = "contraofertă"; conoscibilità = "cognoscibilitate / a face cognoscibil"; perfezionamento = "încheiere / a se încheia"; sostanziale/formale = efectiv / formal; soggetto = entitate; penale = penalitate; dolo o colpa grave = "intenție sau culpă gravă" (mai "fraudă", "rea intenție"); errore materiale manifesto = "eroare materială vădită"; consegna/ritiro = predare / ridicare; ritardo = întârziere, costituzione in mora = punere în întârziere; interessi moratori = dobânzi de întârziere; annullamento del contratto per invalidità (14.1) = "desființarea contractului pentru cauze de nulitate"; ripristino (art. 15) = "repunere în situația anterioară"; maturazione delle Commissioni = "dobândirea Comisioanelor"; a titolo esemplificativo e non esaustivo = "cu titlu exemplificativ și fără caracter limitativ".
- Rinvii: art. / lit. / alin. (comma) / ultima teză; c.c. = Codul civil italian; D.Lgs. = Decretul legislativ (mai "Decretul-lege").
